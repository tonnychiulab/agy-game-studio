# agy-game-studio (Antigravity Game Studio Plugin)

[English](#english) | [繁體中文](#繁體中文) | [日本語](#日本語)

---

<h2 id="english">English</h2>

A seamless port of the OpenAI Codex `game-studio` plugin, reimagined and adapted for the **Antigravity (AGY) CLI**. This plugin provides guided workflows, asset pipelines, UI generation, and playtesting support for developing 2D and 3D browser games through agentic collaboration.

### 💖 Acknowledgements
We would like to express our deepest gratitude to the original **[OpenAI team](https://github.com/openai/plugins)**. They designed the foundational architecture, reference documents, and brilliant workflows that made this tool possible. This project is a community-driven port completely restructured to thrive within the AGY ecosystem.

### Installation
Move or link this repository to your AGY global plugins directory:
```bash
cp -r . ~/.gemini/config/plugins/game-studio
```
